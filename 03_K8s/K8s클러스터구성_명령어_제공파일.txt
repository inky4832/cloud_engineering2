6.  리소스 관리 통합 
////////////////////////////////////////////////////////////////////
//// 작업3:리소스 관리 통합
////
////  도커의  리소스 관리는 cgroup이 담당.
////  K8s의 리소스 관리는 systemd 담당.
////  따라서 충돌이 발생될수 있음. 
////  해결: 한곳에서 일원화하여 리소스를 관리하도록 설정.
///////////////////////////////////////////////////////////////////
> cat <<EOF | sudo tee /etc/docker/daemon.json
{
"exec-opts": ["native.cgroupdriver=systemd"],
"log-driver": "json-file",
"log-opts": {
"max-size": "100m"
},
"storage-driver": "overlay2"
}
EOF

> sudo systemctl restart docker && sudo systemctl restart cri-docker

[확인]
> sudo docker info | grep Cgroup
   Cgroup Driver: systemd
   Cgroup Version: 2

 1. 모든 노드(master, node1, node2 )에서 다음 이미지를 pull 받음

    user1@master:~$ sudo -i
    root@master:~# docker pull docker.io/calico/cni:v3.27.1
    root@master:~# docker pull docker.io/calico/node:v3.27.1
    root@master:~# docker pull docker.io/calico/kube-controllers:v3.27.1

    user1@node1:~$ sudo -i
    root@node1:~# docker pull docker.io/calico/cni:v3.27.1
    root@node1:~# docker pull docker.io/calico/node:v3.27.1
    root@node1:~# docker pull docker.io/calico/kube-controllers:v3.27.1

    user1@node2:~$ sudo -i
    root@node2:~# docker pull docker.io/calico/cni:v3.27.1
    root@node2:~# docker pull docker.io/calico/node:v3.27.1
    root@node2:~# docker pull docker.io/calico/kube-controllers:v3.27.1
