 1. 리눅스(Linux )
 
   1)개요
    -핀란드의 헬싱키대학교의 리누스 베네딕트 토바즈(Linus  Benedict Torvals )가 처음 개발.
    -1991년 8월 26일 리눅스(linux) 배포.
	
   2)발전과정
    -커널(kernel): 프로세스관리, 파일시스템관리, 메모리관리등. (***************)
	-최초 공개된 리눅스 커널: 버전 0.0.1
	-리눅스 재단 : 2007년 설립 ( 삼성전자,메타,애플,........)
	-현재 버전(2025년기준): ubuntu 24.04.1 LTS / Debian 13 
	 * 리눅스 배포판( 커널 + 응용프로그램(메모장,웹브라우저 등))
	 https://namu.wiki/w/Linux/배포판

   3)GNU 프로젝트
   https://www.gnu.org/licenses/license-list.html 
   
     가.개념
	  - GNU is Not Unix ( GNU는 unix아니다) - 그누라고 읽음.
	  - 리처드 스톨만이 시작한 자유 소프트웨어 운동임.
	  - FSF(Free Software Foundation) 협회를 만들어서 자유 소프트웨어 보급 추진.
	  - GNU선언문과 GPL(General Public License)라이선스를 발표함.
	
	 나. 목표
	  - 누구나 자유롭게 프로그램을 사용/복사/수정/배포 가능.
	  - S/W 소스코드를 반드시 공개해야됨 (*********************)
        ex. Linux, MySQL, Apache 등
		
	 다. 오픈소스
      - 1988년 이후에 오픈소스라는 용어가 등장됨.	 
	  
   4)리눅스 배포판
     https://namu.wiki/w/Linux/배포판
	 
	 가. 개념
	   - 커널 + 응용프로그램으로 구성
	   - 레드햇계열, 데비안 계열, 슬랙웨어 계열,...
	   
	 나. Debian(데비안) 계열
	    - ubuntu, Kali Linux
	    - 설치와 설정이 매우 쉽다.
		- 사용자 친화적임
		- 패키지 관리자: apt install 패키지명
		- 패키지 형식: *.deb
	 
	 다. 레드햇 계열
	    - Centos, Rocky Linux
		- 안정적인 OS 임.
		  S/W를 레드햇 저장소에서만 다운로드가 가능.
		  해당 S/W를 검증하기 때문에 안정적임.
		  
		- 패키지 관리자: dnf install / yum install 패키지명
		- 패키지 형식: *.rpm
