		  서버(ubuntu)  <------------------------------------ 클라이언트(window)
		  


		  
		  a. 서버에서 공개키(public Key)와 개인키(private key)를 생성.
		  b. 서버에는 공개키(public key)를 저장하고
		     클라이언트에는 개인키(private key)저장.
			 
		  c. 클라이언트가 서버에 접속할 때 비밀번호 대신에 개인키를 이용해서 접속시도함.
		  d. 서버에서는 클라이언트가 제공한 개인키와 공개키를 이용해서 key pair 검증함.
		     맞으면 로그인성공, 틀리면 로그인 실패.

 1. 프롬프트와 홈디렉터리
 
   1)프롬프트( prompt ) 개념
     - 사용자의 명령을 기다리는 표시.
     - ubuntu의 프롬프트 기본은 다음과 같다.
	 
	   user1@ubuntu:~$
	   
	   user1: 사용자 계정
	   ubuntu: 호스트명  # cat /etc/hostname 에서 확인가능.
	   ~ : user1 사용자의 홈디렉터리 경로 의미.
	       /home/user1
		   
	    $: 일반 사용자에서 사용하는 쉘프롬프트
		   일반 사용자가 할수 있는 작업들.
		    - 프로그램실행.
		    - 파일생성
			- 자신만의 홈디렉터리(ex. /home/user1)안에서만 작업이 가능(******************)
			
		#: root(관리자) 사용하는 쉘프롬프트
		   roor 사용자가 할 수 있는 작업들.
		    - 시스템 전체 권한을 가져서 모든 작업들을 처리가능.
			- 사용자생성
			- 패키지 설치 ( apt install, apt remove 등)
			- 서비스 시작/종료
			
	- 프롬프트에 많은 정보를 얻을 수 있음.
       현재사용자.	
	   호스트명.
	   현재경로.
	   현재 쉘.
	   
	2) 쉘관련 정보 얻기
       -현재사용자 조회: whoami
	   -호스트정보:  hostname	
	   -현재 쉘정보: 환경변수에 쉘정보 저장. SHELL=쉘  ( 윈도우에서는 %JAVA_HOME% , Linux에서는 $SHELL )
	               echo $SHELL
				   /bin/bash (배시쉘)
				   
	   -프롬프트 포맷:  환경변수에 쉘정보 저장. PS1=프롬프트포맷
	                 echo $PS1
					  
					 변경가능. ( export PS1="변경값" )

 2. 일반사용자에서 관리자로 변경하는 방법.
 
   1) 한번만 관리자로 변경해서 실행 ( 초보자에게 권장 )
   
      문법: sudo 명령어
	 
	   ex.  sudo apt update
	        sudo apt install openssh-server
			
			
   2) root로 쉘 변경 ( $ -----> # )
   
      a. 현재 사용자 경로를 유지하고 관리자로 변경하는 방법.
	  
	  문법:   sudo -s ( sudo su 와 비슷 )
	  
	     root@ubuntu:/home/user1# pwd
         /home/user1

	     root@ubuntu:/home/user1# apt update  <== sudo 없이 실행가능.
		 
		 
	  b. root 계정으로 변경하는 방법.

       문법:   sudo su -	  
	   
	      root@ubuntu:~# pwd
          /root

	
		 
   3) root 계정 인증한 캐시 삭제.
   
      문법:  sudo -k

 3.  리눅스 명령어 메뉴얼 보기
 
    1) man 명령어 이용.
	
	  ex.  $ man ls
	  
	     - q 입력해서 빠져나오기
	     -화살표키 이용해서 위/아래로 이동
		 -g: 맨 위로가 가기.
		  G: 만 아래로 가기.
		 -page up/ page down 가능. ( Ctrl + B, Ctrl + F )
		 -검색어 찾기
		  / 입력하고 검색어 입력.
		  
		  ex.
		    /like     n: 다음내용 보여주기

 3) 파일종류 확인방법
 
   가. file 명령어 이용
   
     문법:   file  경로
	 
	     ex.  file /etc/passwd   
		 	    /etc/passwd: ASCII text

		      file /etc
			    /etc/: directory

			  file /dev/sda
			    /dev/sda: block special (8/0)

			  #표준입력/표준출력/표준에러
			  
			  file /dev/stdin  # 0번 ( 표준입력) 자바의 System.in 동일
			  file /dev/stdout # 1번 (표준출력)  자바의 System.out.println 동일
			  file /dev/stderr # 2번 (표준에러)  자바의 System.err.println 동일
			  
   
   
   나. ls -F 이용.
		 
		ex.    
		
		       ls -aF  /etc
		
		   / : 디렉터리 의미
		   @ : 심볼릭 링크 의미
		   * : 실행파일 의미
		   이외: 일반파일 의미

 4) 디렉터리 계층 구조  
  
    -리눅스에는 윈도우 처럼 C:\, D:\ 같은 드라이브 개념이 없다.
	-단일 계층구조(트리구조)로 관리하고 시작은 / (root 디렉터리)임.


					/  (root 디렉터리) <= root계정의 /root가 아님.
					
					|
	 bin   etc    usr    home   tmp  dev 
						  |
						 user1
	                
	-현재 디렉터리의미:   . 사용.
	 부모 디렉터리의미:  .. 사용.
	 
	- 주요 디렉터리 소개

      /bin : 명령어 저장.
	  /home : 일반 사용자 홈디렉터리 ex. /home/사용자명
	  /root : root 사용자 홈디렉터리
	  /usr  : 응용프로그램 저장.
	  /var  : 로그/변경 데이터 저장.
	  /tmp  : 임시 디렉터리
	  /etc  : 리눅스 설정파일. ex.  /etc/passwd,  /etc/shadow
	  
	- 디렉터리 계층구조 쉽게 관리가능한 패키지.
	  
	    sudo apt update & sudo apt install tree
		
		tree 
		tree -d   # 디렉터리만 출력

 5) 홈 디렉터리(home directroy)
 
   가. 개념.
    - 사용자에게 할당된 디렉터리임. 처음 사용자(계정)을 생성할 때 제공됨.
	- 기본디렉터리는 /home/사용자명 으로 만들어짐. ( 경로 수정 가능 )
	- 홈디렉터리는 ~ 로 표시.
	- 홈디렉터리는 환경변수로 관리.  HOME=/home/user1
	   
	     echo $HOME
  
   나. 홈 디렉터리 경로

	 => 리눅스는 일반사용자와 root 사용자의 홈디렉터리를 명확하게 구별하여 관리함.(보안이슈)

	9) 디렉터리 내용 보기
	
	 -문법:
	       ls [옵션] 디렉터리 디렉터리 ....
		   
	 -옵션:
             -a   :  숨김 파일을포함하여모든파일목록을출력
			▪-d   :  지정한 디렉터리자체정보를출력
			▪-i   :  inode 번호출력
			▪-l    : 상세정보 출력
			▪-F   :  파일의종류를표시
			▪-h   :  파일크기값을가독성있게출력 ex.  4096 ----> 4k
			▪-R   : 하위 디렉터리목록까지출력	 
		   
		  ex.  ls -al  /etc
		       
			   ls -R  /etc
			   
			   ls -ahl /etc
			   
	[student@student ~]$ ls -l
    d       rwxr-xr-x.     2           user1       user1        4096           2월13 22:14      공개
  파일종류   권한           하드링크갯수   계정(소유자)  그룹         크기            생성/수정 날짜    디렉터리명
            rwx:소유자권한
		    r-x:그룹권한
			r-x:이외권한
