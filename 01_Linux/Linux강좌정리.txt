		  서버(ubuntu)  <------------------------------------ 클라이언트(window)
		  


		  
		  a. 서버에서 공개키(public Key)와 개인키(private key)를 생성.
		  b. 서버에는 공개키(public key)를 저장하고
		     클라이언트에는 개인키(private key)저장.
			 
		  c. 클라이언트가 서버에 접속할 때 비밀번호 대신에 개인키를 이용해서 접속시도함.
		  d. 서버에서는 클라이언트가 제공한 개인키와 공개키를 이용해서 key pair 검증함.
		     맞으면 로그인성공, 틀리면 로그인 실패.

			 ssh-keygen  -q  -N  ""  -f  ubuntu_user1_key.pem

 1. 프롬프트와 홈디렉터리
 
   1)프롬프트( prompt ) 개념
     - 사용자의 명령을 기다리는 표시.
     - ubuntu의 프롬프트 기본은 다음과 같다.
	 
	   user1@ubuntu:~$
	   
	   user1: 사용자 계정
	   ubuntu: 호스트명  # cat /etc/hostname 에서 확인가능.
	   ~ : user1 사용자의 홈디렉터리 경로 의미.
	       /home/user1
		   
	    $: 일반 사용자에서 사용하는 쉘프롬프트
		   일반 사용자가 할수 있는 작업들.
		    - 프로그램실행.
		    - 파일생성
			- 자신만의 홈디렉터리(ex. /home/user1)안에서만 작업이 가능(******************)
			
		#: root(관리자) 사용하는 쉘프롬프트
		   roor 사용자가 할 수 있는 작업들.
		    - 시스템 전체 권한을 가져서 모든 작업들을 처리가능.
			- 사용자생성
			- 패키지 설치 ( apt install, apt remove 등)
			- 서비스 시작/종료
			
	- 프롬프트에 많은 정보를 얻을 수 있음.
       현재사용자.	
	   호스트명.
	   현재경로.
	   현재 쉘.
	   
	2) 쉘관련 정보 얻기
       -현재사용자 조회: whoami
	   -호스트정보:  hostname	
	   -현재 쉘정보: 환경변수에 쉘정보 저장. SHELL=쉘  ( 윈도우에서는 %JAVA_HOME% , Linux에서는 $SHELL )
	               echo $SHELL
				   /bin/bash (배시쉘)
				   
	   -프롬프트 포맷:  환경변수에 쉘정보 저장. PS1=프롬프트포맷
	                 echo $PS1
					  
					 변경가능. ( export PS1="변경값" )

 2. 일반사용자에서 관리자로 변경하는 방법.
 
   1) 한번만 관리자로 변경해서 실행 ( 초보자에게 권장 )
   
      문법: sudo 명령어
	 
	   ex.  sudo apt update
	        sudo apt install openssh-server
			
			
   2) root로 쉘 변경 ( $ -----> # )
   
      a. 현재 사용자 경로를 유지하고 관리자로 변경하는 방법.
	  
	  문법:   sudo -s ( sudo su 와 비슷 )
	  
	     root@ubuntu:/home/user1# pwd
         /home/user1

	     root@ubuntu:/home/user1# apt update  <== sudo 없이 실행가능.
		 
		 
	  b. root 계정으로 변경하는 방법.

       문법:   sudo su -	  
	   
	      root@ubuntu:~# pwd
          /root

	
		 
   3) root 계정 인증한 캐시 삭제.
   
      문법:  sudo -k

 3.  리눅스 명령어 메뉴얼 보기
 
    1) man 명령어 이용.
	
	  ex.  $ man ls
	  
	     - q 입력해서 빠져나오기
	     -화살표키 이용해서 위/아래로 이동
		 -g: 맨 위로가 가기.
		  G: 만 아래로 가기.
		 -page up/ page down 가능. ( Ctrl + B, Ctrl + F )
		 -검색어 찾기
		  / 입력하고 검색어 입력.
		  
		  ex.
		    /like     n: 다음내용 보여주기

14) 파일 및 디렉터리 복사

      문법:  
	        cp [옵션]  원본  대상(타겟)
		
	  특징:
	         원본 및 대상: 파일이거나 디렉터리가 될 수 있음.
			 원본:  여러개 지정 가능
			 
			 ex.
			 
			     cp  원본파일   타겟파일
				 cp  원본파일1  원본파일2 ..  타겟디렉터리
				 cp -r 디렉터리 원본파일1  원본파일2 ..  타겟디렉터리
				 
	  옵션: 
	  
	       -i  : interactive 가능.
		   -p  : 원본파일의 속성(mode,소유자,시간)까지 유지되어 복사됨.
		   -r  : 원본에 디렉터리가 있는 경우. recursive
		   
		
		실습:
		      cp /etc/passwd     ./users.txt  
			  cp /etc/passwd     ./logs2/users.txt  # 타겟에 복사될 디렉터리 포함가능.
			  
			  cp -i /etc/passwd     ./users.txt  # 덮어쓰기 전에 물어봄.
			  
			  cp   hello.txt   users.txt   first/   # 있으면 복사되고 없으면 오류출력됨.
			  
			  cp  -r log2 users.txt  first/  # 원본이 디렉터리인 경우에는 -r 옵션 필수.
			  
		실습2:  -p 실습방법
		
		      -users.txt 의 소유자를 확인하자. <== user1 이 소유자.
			  
			  -관리자 권한으로 복사
			  
			    sudo cp users.txt  u.txt  <== u.txt 의 소유자?  root 임.
				
				sudo cp -p users.txt  u2.txt  <== u2.txt 의 소유자?  user1 임.

17) 파일 및 디렉터리 찾기

  문법:    find 경로(상대/절대) [옵션]  대상(타겟)
			   
  옵션: 			   
      -name   :   이름검색 ( 대소문자 구분)
	▪-iname :   이름검색( 대소문자 무시)
	▪-type f   :   파일
	▪-type d  :  디렉터리
	▪-size  크기 :  파일크기기준
	▪-user 사용자: 사용자기준
	▪-exec  명령어:  명령어실행
	▪-delete  :   삭제
	▪-ls     :  find후에 ls 실행
	▪-maxdepth n    : 깊이 제한, 다른 옵션보다 가장 먼저 사용해야됨. 양수만 가능
	

    실습>
	     mkdir projects
		 touch projects/report.txt
		 touch projects/todo.txt
		 touch projects/todo2.txt
		 touch projects/error.log
		 touch projects/alert.log		 
		 
		 echo "todo" >> projects/todo.txt
		 echo "error" >> projects/error.log
		 echo "alert" >> projects/alert.log	 
		 
		 tree projects
		 
		 find projects -name  todo.txt
		 find projects -name  TODO.txt  # 대소문자 구별됨.
		 
		 find projects -iname  TODO.txt  # 대소문자 무시
		 
		  find projects -name  to*.txt   # 와일드카드 사용 가능.
		  
		 find projects -name  todo2.txt -delete  # 찾아서 삭제
		 
		 sudo find /etc -name  passwd -ls    # 권한 설정 가능, 중첩디렉터리 조회가능, 조회 후 ls 실행가능
		       298857      4 -rw-r--r--   1 root     root         2907 May 26 14:31 /etc/passwd
               264578      4 -rw-r--r--   1 root     root           92 Feb 22  2024 /etc/pam.d/passwd

		 
		 find /etc -type d  # 디렉터리만 찾기
		 find /etc -type f  # 파일만 찾기
		 
		 
		 find projects -name  "*.log" -exec 명령어 \;  # \와 ; 필수
		 
		 find projects -name  "*.log" -exec cat {} \; # {}는 find된 파일이 치환되는 영역포시
		 find projects -name  "*.log" -exec rm {} \;
 		 
		 -maxdepth
		 sudo find /etc -name  passwd -ls  # 검색결과는 2개 (/etc/passwd, /etc/pam.d/passwd )
         sudo find /etc -maxdepth 1 -name  passwd -ls  	 # 검색결과 1개	 (/etc/passwd )

		▪-c  :   개수

		▪-v   :   반대 검색(inverse)
		▪-E  :   확장정규식, 반드시 대문자 -E ( 검색어 열러개 지정 )
		▪-i :   대소문자무시

	   # 파일생성 + 여러 라인에 데이터 저장 ( Here Document라고 부름 )

19) 하드링크 ( hard link)

  -개념:  같은 inode 값을 갖는 다른 파일.
         /////////////////////////////
			inode ?
			- 파일(파일,디렉터리,장치,...)의 실제 저장되는 주소값 의미.
		 ///////////////////////////////
		 
  - 문법:
          ln  원본파일 대상파일(타겟)
		  
  - 특징:
        디렉터리 지정불가 ( 디렉터리는 동일한 주소값을 가질수 없기 때문)
		inode가 같으면 데이터도 동일.
		한쪽이 수정되면 다른쪽도 영향을 미침.
		한쪽이 삭제되면 수정과 다르게 다른쪽에는 영향이 없음.
		( 삭제의미는 inode 참조하는 링크를 삭제하는 것이다.)
		
  - 목적:
       백업용도( 하나가 삭제가 되고 나머지 유지 )
	   보안이슈 ( 중요한 파일명을 노출하지 않을 수 있음 )
	   
	   
	실습:
          echo "hello" > m.txt # 원본파일

		   ln m.txt  m_copy.txt # 하드링크
	   
	      ls -il  # -i 는 inode 확인
	      
			1060500 -rw-rw-r-- 2 user1 user1    6 May 28 14:23 m_copy.txt
			1060500 -rw-rw-r-- 2 user1 user1    6 May 28 14:23 m.txt

		  cat m.txt  m_copy.txt      # 내용이 똑같은지 확인.
		  
		   echo "world" >> m.txt # 원본파일 수정. append
