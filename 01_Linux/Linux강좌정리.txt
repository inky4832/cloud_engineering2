 1. 리눅스(Linux )
 
   1)개요
    -핀란드의 헬싱키대학교의 리누스 베네딕트 토바즈(Linus  Benedict Torvals )가 처음 개발.

   2)발전과정

	-리눅스 재단 : 2007년 설립 ( 삼성전자,메타,애플,........)
	-현재 버전(2025년기준): ubuntu 24.04.1 LTS / Debian 13

  1) 가상머신 S/W
  
    가. 개념
	
       Ubuntu 리눅스
   --------------------------
      가상머신 ( VirtualBox, VMWare Workstatiion Pro(현재는 무료) )
   ---------------------------
       윈도우(window 11)-호스트 PC
     ------------
        H/W
		
    나. VMWare Workstatiion Pro 다운로드 및 설치
	  
	  https://support.broadcom.com/group/ecx/free-downloads

       * 삭제
	    -VMWare uninstall
		-C:\ProgramData\VMware 명시적으로 삭제.
		-C:\Users\User\AppData\Roaming\VMware 명시적으로 삭제.
		
	다. 실행시 반드시 관리자 권한으로 실행하자.	
	
	라. VMWare에서 사용하는 IP를 고정하자.
	
	     VMnet8 NAT      :  172.16.8.0   255.255.255.0  <== CIDR 표기법:  172.16.8.0/24
		 
		 VMnet1 host-only:  172.16.1.0   255.255.255.0  <== CIDR 표기법:  172.16.1.0/24
		 
	
	    a. NAT 용도 ( Network Address Tranlation )
		  - ubuntu에서 사용하는 사설IP를 인터넷이 가능한 공용IP로 변경하는 역할.
		  
		     ex. 
			      ubuntu  ( 사설 IP: 172.16.8.10 )
				    |
				  VMWare NAT
				    |
				  윈도우 PC ( 호스트)
				    |
				  공유기(인터넷)
				  
		b. host-only 용도
		 - ubuntu와 host인 윈도우 PC통신용.
		    
			  ex. 
			      ubuntu  ( 사설 IP: 172.16.8.10 )
				    |
				  VMWare host-only
				    |
				  윈도우 PC ( 호스트)
				  
	    c. 전체 아키텍처 ( 반드시 알고있어야 됨 )
		
		 호스트(윈도우 PC )
		 |
		 |    VMWare
		 |    |
		 |    |   Linux           Linux
		 |    |   |               |
		 |    |   | eth(NIC)      | eth(NIC: Network Interface Card)
		      |   |-----          |----------
			   
			    VMnet8    VMnet1
		 |    |----------------------
		 |   172.16.8.0   172.16.1.0
		 |---------------------------
	
	 마. VMware에 Linux( Ubuntu 24 설치 )
	 
	    -  Ubuntu 24 해당하는 이미지 다운로드.
		
		https://ubuntu.com/download/desktop

        - Ubuntu Server: GUI 없음. CMD창에서 명령어만 사용 가능.
		- Ubuntu Desktop: GUI 있음. 초보자에게 추천  (ubuntu-24.04.4-desktop-amd64.iso )
		
	 
	   - VMware에 Ubuntu 24 설치.
	   
	   
	 바. Ubuntu에 고정 IP 설정하기.
	 
	     Address: 172.16.8.10
		 NetMask(서브넷마스크): 24  ( 255.255.255.0 과 동일 )
		                     용도: 사용중인 네트워크가 동일한 네트워크인지를 확인용도.
							 CIDR 표기법:   172.16.8.10/24
							               
										   172.16.8: 네트워크주소
										   10:  호스트주소
										   
										   전체IP 주소 범위:  172.16.8.0 ~ 172.16.8.255
										                    
										   -2개 :   172.16.8.0 사용불가(네트워크자체주소)
										            172.16.8.255 사용불가 (브로드캐스트주소:같은네트워크에 속한 모든 장치에 전달용)
											실제 사용가능한 IP 주소: 172.16.8.1 ~ 172.16.8.254
										   ----------------
										   172.16.8.10/16
							               
										   172.16: 네트워크주소
										   8.10:  호스트주소
										   
										    전체IP 주소 범위:  172.16.0.0 ~ 172.16.255.255
										   
		 
		 ex. 
		 
		    서브넷1 (ubuntu)                       서브넷2 (Rocky Linux)
			172.16.8.10                           172.16.9.100  
			255.255.255.0                         255.255.255.0
			
			IP번호: 172.16.8.10
			
			IP번호 2진수:   10101100.00010000.00001000.00001010
			
			서브넷 2진수:   11111111.11111111.11111111.00000000
			   ----------------------------------------------------
			      and연산: 10101100.00010000.00001000.00000000
			
				 10진수:  : 172.16.8.0 <== 서브넷1 의 네트워크임.
			------------------------------------------------
			
			IP번호: 172.16.9.100  
			IP번호 2진수: 10101100.00010000.00001001.01100100
			서브넷 2진수:  11111111.11111111.11111111.00000000
			
			 -------------------------------------------------
			    and 연산: 10101100.00010000.00001001.00000000
				
				10진수:    172.16.9.0 <== 서브넷2 의 네트워크임.
			
			//////////
			만약 172.16.8.200 인경우 서브넷1과는 같은 네트워크가되고 서브넷2는 다른네트워크가 된다고 할 수 있음.
