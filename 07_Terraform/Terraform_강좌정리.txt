8. Resouce Lifecycle 
/////////////////////////////////////			 

https://developer.hashicorp.com/terraform/language/block/resource#lifecycle

   1.개념 
     Resource의 생성/수정/삭제 방식을 제어 가능 
	 

   2. 문법
   
     resource "타입" "라벨"{
	   
	    ...
		lifecycle{
			create_before_destroy=true
			prevent_destroy = true 
		    ignore_changes = [ <attribute> ]
			replace_triggered_by=[ 의존성 ]
		}
	}	
	
	
	 가. create_before_destroy=true|false
	   - 기본적으로 resource 교체할 경우 동작 방식은 다음과 같다. 
	     기본적으로 이전 리소스(A)를 먼저 삭제하고 나중에 새로운 리소스(A2)가  생성됨. 
		 만약 서비스중이라면 문제가 심각해짐.
		 create_before_destroy=true 지정하면 A2가 먼저 생성되고 나중에 A가 삭제됨.
		 
	 나. prevent_destroy = true 
	   - terraform destroy 하면 Terraform이 관리했던 모든 리소스가 삭제됨. 
	     중요한 Resource의 삭제방지하는 방법임.
	 
	
	다. ignore_changes = [ <attribute> ]
	  -  Terraform이 관리하는 리소스의 attribute 값을 외부에서 변경 시, 해당 변경사항을 Terraform이 무시하는 기능 
	  
	    ex.
		  lifecycle{
		      ignore_changes =[tags, ....]
	      }
	   
	
	라. replace_triggered_by=[ 의존성 ]
	
	  - (EC2의 )직접적인 Argument 변경 없이도  의존성이 있는 다른 Resource(Subnet)가 변경되면
        현재 Resource(EC2)가 교체하도록 지정가능.	  
	
	   ex. 
	   
	       lifecycle{
		      replace_triggered_by =[ aws_subnet.public-inky4832.id]
	      }

9. 빌트인 함수 (내장함수)
/////////////////////////////////////	

    https://developer.hashicorp.com/terraform/language/functions
	
	1. numeric 함수 
	
	   max(12, 54, 3) => 54
	   min(12, 54, 3) => 3 
	   ceil(5.1) => 6, 소수점 올림 
	   floor(4.9) => 4, 소수점 버림 
	   pow(3, 2) ==> 8 , 거듭제곱 
	   abs(-12.4) => 12.4, 절대값 
	   
	2. string 함수 

	   lower("HELLO")
	   upper("hello")
	   replace("1 + 2 + 3", "+", "-")
       format("%s, %s", "Ander","Ford")


       join("-", ["foo", "bar", "baz"]) ==> "foo-bar-baz"
	   split(",", "foo,bar,baz") ==> ["foo","bar","baz",]
	   
	   startswith("hello world", "hello") => true 
	   endswith("hello world", "world") => true 
	   substr("hello world", 1, 4)
	   
	   
	   trim("   hello! world.!  ", "! ") <== 특정문자 삭제 
	   trimspace("  hello\n\n    ")   <== 공백문자 삭제 
       length("hello") ==> 5

    3. collection 함수 
	  
	    contains(["a", "b", "c"], "a") ==> true 
		length(["a", "b"]) ==> 2
		concat(["a", ""], ["b", "c"]) ==> ["a","","b","c"]
		distinct(["a", "b", "a", "c", "d", "b"]) <== 중복제거
		
		flatten([["a", "b"], [], ["c"]]) => ["a", "b", "c"],  2차원을 1차원으로 축소.
		
		keys({a=1, c=2, d=3}) ==> ["a","b","c"],  map에서 key만 추출 
		values({a=3, c=2, d=1})  ==> [3,2,1],  map에서 value만 추출 
		
		sum([10, 13, 6, 4.5]) ==> 33.5,  컬렉션 총합
		
		sort(["e", "d", "a", "x"]) <== 오름차순 정렬 
		slice(["a", "b", "c", "d"], 1, 3)
		reverse([1, 2, 3])
		
		merge({a="b", c="d"}, {e="f", c="z"}) ==> {a="b", e="f", c="z"}, map계열 병합 
        lookup({a="ay", b="bee"}, "a", "what?") ==> ay,   일치하는 key값 없으면 default반환


    4. encodig 함수 
	
	  jsonencode({"hello"="world"}) ==> "{"hello"="world"}" ,  JOSN ==> 문자열 

	   jsondecode("{\"hello\": \"world\"}") ==> {"hello"="world"},  문자열 ==> JSON 
	   
	   base64encode("Hello World") ==>  SGVsbG8gV29ybGQ= 
	   base64decode("SGVsbG8gV29ybGQ=") ==>  Hello World
	   
	   
	5. file 함수 
	
	  file("${path.module}/hello.txt") ==> Hello World,  지정된 경로의 파일내용을 문자열로 읽음.
	  
	  fileexists("${path.module}/hello.txt") => true , file 존재여부 확인 
	  
	  basename("foo/bar/baz.txt") ==> baz.txt,  지정된 경로의 가장 마지막 파일(디렉터리) 반환 
	  
	  dirname("foo/bar/baz.txt") ==> foo/bar, ,  지정된 경로의 가장 마지막 파일(디렉터리)제외한 나머지 반환 
	  
	
	6.  date and time 함수 
	
	      timestamp() ==> 2018-05-13T07:44:12Z 
		  formatdate("MMM DD, YYYY", "2018-01-02T23:12:01Z") ==>  Jan 02, 2018,  Timestamp를 지정된 format으로 출력
		  timeadd("2024-08-16T12:45:05Z", "10m") ==> "2024-08-16T12:55:05Z",  지정된 시간을 더함.
	      timeadd("2024-08-16T12:45:05Z", "-10m") ==> "2024-08-16T12:35:05Z",  지정된 시간을 뺌
		   
	7.  type 변환 함수 
	
		tolist(["a", "b", "c"])
		toset(["a", "b", "c"])
		tomap({"a" = 1, "b" = 2})
		
		tostring(1) ==> "1"
		tostring(true) ==> "true"
		
		tonumber("1") ==> 1
		parseint("100", 10)  ==> 100
		
		try([문장1,문장2,...]) <=== 지정된 문장을 실행해서 오류가 없는 문장의 실행결과를 반환함.
		
		can(tonumber("1"))=> true,   표현식이 오류없이 실행가능한지를 체크.
		can(tonumber("aaa"))=> false

  https://developer.hashicorp.com/terraform/language/backend
  
   1. 개념 
   
    - 기본적으로 Terraform은 인프라의 현재 상태를 State라는 데이터로 관리함.
	 ( 이 파일안에 Terraform이 생성한 AWS 리소스와 Terraform 코드의 연결정보등이 저장됨 )
	 
	    Terraform Code(main.tf) <-------------> terraform.tfstate <-------------------> AWS 리소스 
	
	- Terraform Backend는 State파일을 어디에 저장하고 어떤 방식으로 관리할지를 결정하는 설정임.(****)
	
	
   2. 종류 
   
    1) Local Backend
	   - 기본 
	   - 문법 
	   
	     terraform {
			  backend "local" {
				path = "terraform.tfstate"
			  }
			}

	      
	2) Remote Backend
	  - 원격인 AWS S3에 저장 
	  - 문법 
	   
	     terraform {
		  backend "s3" {
			bucket = "" 
			key    = ""
			region = ""
			profile= ""
		  }
		}
