   1. Terraform CLI 설치( Go 언어로 개발 )
   
      - Terraform을 실행하기 위한 도구. 
	  - Terraform을 실행하기 위한 GUI 제공 안됨.
	 
     1) 윈도우 zip 파일 다운로드 및 압축해제
	 
	  https://developer.hashicorp.com/terraform/install
	  
	 2) terraform.exe 파일을 PATH에 추가 
	 
	   PATH=C:\cloud_engineering\terraform_study\terraform_1.15.8_windows_386;%PATH%
	   
	   
	 3) CMD에서 명령어 확인
	 
	    terraform version
	

    4) Terraform 주요 명령어 

       - terraform init  : Terraform 프로젝트 초기화
						   Provider 다운(AWS Provider ), .terraform 디렉터리 생성, lock file파일
						   
	   - terraform validate : Terraform 코드(HCL) 문법검사 
	   - terraform fmt       : Terraform 코드(HCL)를 표준 형식으로 만듬.
	   - terraform plan      : Terraform 코드(HCL)와 AWS Infra 비교하여 변경사항을 미리 확인.
	   - terraform apply     : Terraform 계획을 실제 AWS에 적용하여 Infra 구축.
	   - terraform destroy   : Terraform이 관리하는 모든 리소스를 삭제.

3. HCL ( HashiCorp Language) 문법 정리 
/////////////////////////////////////  

  1. 데이터 종류 
  
    https://developer.hashicorp.com/terraform/language/expressions/types

     1) Primitive types
	    
		가. string
		   ex.  "hello"
		나. number
		   ex.  100,   3.14
		다. bool 
		   ex. true/false 
	 
	 
	 2) Collection types (  complex types, structural types )

        라. list ( 순서있고 중복 허용 가능 )
		   ex.   ["us-west-1a", "us-west-1c"]
		   
		마. set   ( 순서없고 중복 불가)
		https://developer.hashicorp.com/terraform/language/expressions/types#sets 참고해서 사용하자.

		바. map 
		 ex. {name = "Mabel", age = 52}
		      또는
			  {name : "Mabel", age : 52}
		
	3) Special vaue 
	
	   사. null
	   
	--------------------------------------------
	  실습1:  데이터 종류 
	  
	    
	     1. main.tf  작성 
		 ##################################################
			# 문자열/숫자/리스트/맵  작성하기
			##################################################

			locals {
			  
			  # 문자열 값
			  project_name = "terraform-practice"

			  # 숫자 값
			  instance_count = 2

			  # Boolean 값
			  enable_monitoring = true

			  # List
			  availability_zones = [
				"ap-northeast-2a",
				"ap-northeast-2c"
			  ]

			  # Map
			  common_tags = {
				Project     = "terraform-practice"
				Environment = "dev"
				ManagedBy   = "Terraform"
			  }

			  common_tags2 = {
				Project2 : "terraform-practice2"
				Environment2 : "dev2"
				ManagedBy2 : "Terraform2"
			  }

			}

  2. 보간법 ( interpolation )		   
  
     https://developer.hashicorp.com/terraform/language/expressions/strings#interpolation
	 
	 1)개념 
	  - 문자열 안에 임의의 변수값 설정하는 기능. 
	  - 자바의 백틱(back-tick) 역할 
	  
	 2)문법 
	 
	   ${변수명} 이용 
	   
	  ex. "Hello, ${var.name}!"

  -----------------------------------------
    실습2 - 보간법 
	
	  1) main.tf 작성 
	  
	    ##################################################
		# 문자열 조합하기
		##################################################

		locals {
		  
		  # 문자열
		  project_name = "terraform"

		  # 실행 환경
		  environment = "dev"

		  # 숫자
		  instance_count = 2

		  # Boolean
		  enable_monitoring = true

		  # List
		  availability_zones = [
			"ap-northeast-2a",
			"ap-northeast-2c"
		  ]

		  # Map
		  common_tags = {
			Project     = local.project_name
			Environment = local.environment
			ManagedBy   = "Terraform"
		  }

		  # 문자열 조합
		  resource_name = "${local.project_name}-${local.environment}-vpc"
		}
		
		 2) 실행 
		 
		  terraform init
		  terraform console
			> local.common_tags
			{
			  "Environment" = "dev"
			  "ManagedBy" = "Terraform"
			  "Project" = "terraform"
			}
			> local.resource_name
			"terraform-dev-vpc"

  3. output values 
  
    https://developer.hashicorp.com/terraform/tutorials/configuration-language/outputs
  
  
    1) 개념 
	  - Terraform의 리소스를 생성한 후 생성 결과를 확인할 수 있는 방법임.
	  
	2) 기본구조 
	 
	   - 파일명: outputs.tf 
	
	   문법:
	   
	      output "이름"{
		  
		     description="설명"
			 value="값"
			 sensitive=true|false 
		  
		  }
	     
	 3) 명령어 실행 
	 
	     terraform init
	     terraform apply   <== output 자동으로 출력됨 
		 terraform output  
		 terraform output 이름   
		 
		 
	실습3- output 실습 
	
	  1) outputs.tf 
	  
	     
		##################################################
		# Output으로 값 확인
		##################################################

		output "project_name" {
		  value = local.project_name
		}

		output "resource_name" {
		  value = local.resource_name
		}

		output "first_availability_zone" {
		  value = local.availability_zones[0]
		}

		output "environment_tag" {
		  value = local.common_tags["Environment"]
		  sensitive = true
		}

     2) 실행 
	 
	    terraform init
		terraform apply

		Changes to Outputs:

  4. 변수 (variable )
  
    1) 변수 종류
	
	 가. input variable
	    - 외부에서 주입 받는 값을 저장하는 변수. 변경 가능 (***************)
	 나. local variable
	    - 내부에서 사용하기 위해 만든 계산된 값을 저장하는 변수. 변경 불가능 ( readonly )
	 다. output value
	     -외부로 출력할 때 사용하는 변수
	
	
	2) local variable
	
	  -개념 
	   내부에서 사용하기 위해 만든 계산된 값을 저장하는 변수. 변경 불가능 ( readonly )
	   
	  -문법 
	  
	     locals {
		 
			변수명=값 
		    변수명=값 
		 }
		 
	  -참조방법 
	  
	     local.변수명
